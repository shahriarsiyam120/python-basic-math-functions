# 🐍 Python Basic Math Functions

A collection of Python programs focused on **functions, basic mathematics, conditional logic, and problem-solving**.

This repository documents my practice in building strong **Python programming fundamentals** through simple mathematical problems.

## 📚 Programs Included

| Program                   | Description                                              |
| ------------------------- | -------------------------------------------------------- |
| `divisible_by_3_and_5.py` | Check whether a number is divisible by both 3 and 5      |
| `multiple_2_3.py`         | Check whether a number is a multiple of 2, 3, or both    |
| `absolute_value.py`       | Calculate the absolute value of a number                 |
| `absoluate_diff.py`       | Calculate the absolute difference between two numbers    |
| `point_circle.py`         | Check whether a point is inside, outside, or on a circle |
| `largest_triangle.py`     | Find the largest among three triangle sides              |
| `bmi.py`                  | Calculate BMI and determine the BMI category             |
| `simple_interested.py`    | Calculate Simple Interest and Total Amount               |
| `compound_interested.py`  | Calculate Compound Interest and Final Amount             |
| `final_price_discount.py` | Calculate discount amount and final price                |
